# 🎓 Campus Sarnival

A responsive and interactive college website developed as part of the Hackathon event **"Campus Sarnival"**. This project provides a modern digital face for a college, integrating essential features to enhance accessibility, communication, and engagement with students, faculty, and visitors.

## 🚀 Features

- 🏫 Interactive homepage showcasing the college infrastructure
- 📰 News & Events section
- 🎯 Courses and Departments listing
- 📅 Academic calendar and schedules
- 📷 Gallery for photos and media
- 📞 Contact form with location map
- 💬 Testimonials or student highlights

## 🛠️ Tech Stack

- **Frontend:** React.js
- **Frameworks:** Bootstrap 
- **Optional Add-ons:** jQuery, AOS for animations
